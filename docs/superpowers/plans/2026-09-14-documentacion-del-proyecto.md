# Plan de documentación del proyecto

**Objetivo:** explicar en español el funcionamiento actual por carpetas y establecer su mantenimiento junto con el código.

**Arquitectura documental:** índice en `docs/arquitectura/README.md`, especificaciones por área y una guía de mantenimiento. `README.md` será la entrada del repositorio y `AGENTS.md` conservará las instrucciones para futuras modificaciones.

**Tecnologías analizadas:** Next.js 14.1.0, React 18, TypeScript, Tailwind, Sass, Context y next-themes.

**Solicitud de referencia:** analizar primero el proyecto, crear varios Markdown por carpetas con un estilo de especificaciones y actualizarlos cuando cambie el proyecto.

## Restricciones

- Describir el contenido del árbol de trabajo, incluidos los cambios locales anteriores.
- Escribir en español y diferenciar implementación, datos disponibles y propuestas.
- Conservar el código, los recursos y los documentos previos del usuario.
- Mantener esta entrega limitada a documentación; no corregir los problemas encontrados.
