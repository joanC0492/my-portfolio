# Título

Tokenovate: actualización de rutas, navegación y CTA en WordPress

## Resumen para tarjeta

Configuré una redirección 301, unifiqué la terminología de navegación y corregí el destino del CTA de solicitud de demo para mantener la consistencia funcional y de contenido del sitio.

## Contexto

Tokenovate es un sitio corporativo en WordPress orientado a tecnología financiera y normalización de datos.

## Problema

El sitio requería actualizar una ruta antigua, alinear textos visibles en el header y footer, y corregir el destino de una llamada a la acción.

Esto generaba inconsistencias entre la URL disponible, la terminología utilizada en la navegación y el flujo hacia la página de solicitud de demo.

## Mi participación

Realicé los ajustes en WordPress y validé que la redirección, los enlaces y los textos fueran consistentes entre las distintas áreas del sitio.

También revisé el comportamiento en diferentes navegadores y resoluciones.

## Solución

Se configuró una redirección 301 desde:

`/use-cases/trade-data-normalisation/`

hacia:

`/use-cases/data-normalisation/`

Además:

- Se actualizaron los textos del header y footer para utilizar **Data Normalisation**.
- Se corrigió el enlace del CTA **Request a Demo** para dirigirlo a `/book-a-demo/`.
- Se realizaron pruebas funcionales y visuales.
- Se validó el comportamiento mediante BrowserStack.

## Tecnologías

WordPress, PHP, HTML, CSS, JavaScript, redirecciones HTTP, BrowserStack y Git.

## Resultado

La URL anterior quedó redirigida permanentemente hacia la nueva. La navegación pasó a utilizar una terminología consistente y el CTA **Request a Demo** quedó enlazado correctamente con la página de reserva de demo.
